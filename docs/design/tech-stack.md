## 2. 技術選定・管理ルール

- 原則として、本ドキュメントに定義した技術を優先して使用する。
- 既存の技術で実現できる場合は、同じ役割を持つ技術を新たに導入しない。
- 新たな技術を導入する場合は、導入目的、既存技術との差異、保守性への影響を確認する。
- パッケージのバージョンは本ドキュメントに記載せず、依存関係ファイル（`package.json`、`pyproject.toml`等）で管理する。
- 以下の場合は「1. 技術スタック一覧」を更新する。
  - 技術スタックを変更したとき
  - 各技術の状態（採用済み・採用予定・検討中）が変化したとき
  - 依存関係ファイル・設定ファイルと差異があるとき（ファイル側を正とする）
