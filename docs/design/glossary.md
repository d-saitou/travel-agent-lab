# 用語集

| 用語 | 定義 |
|---|---|
| 旅行履歴 | ユーザーが登録した過去の旅行の記録 |
| 旅行プラン | エージェントが提案する今後の旅行の計画。提案・修正中のものと、ユーザーが承諾して登録したものを含む |
| 会話 | 旅行プランの相談における、ユーザーとエージェントの一連のやり取り |
| 会話メタ情報 | 会話を識別・管理するための情報（会話ID、タイトル等） |
| 処理状態 | エージェントの実行状態（提案・修正中の旅行プラン、承諾待ち等） |
| 会話履歴 | 会話メタ情報と会話内容・処理状態の総称 |
| サインインID | ユーザーがサインイン時に入力する識別子 |
| 内部シークレット | frontendからbackendへのリクエストであることを証明する共有の秘密値 |
| セッショントークン | サインイン時に発行し、セッションCookieで受け渡す乱数 |
| 埋め込みベクトル | テキストの意味を数値の配列で表したもの。類似度検索に使う |
| RAG検索 | 埋め込みベクトルの類似度で旅行履歴・旅行プランを検索し、応答生成の文脈に含める処理 |
| チェックポインター | 会話内容・処理状態をDBに保存するLangGraphの仕組み |
| Human-in-the-loop | データを変更するエージェントのツールを、ユーザーの承諾を得てから実行する仕組み |
| ツール呼び出しID | LLMの応答でツール呼び出しごとに付与される識別子 |
| Dev Host | Dev Containerの外側の開発環境（WSLインスタンス：ubuntu-for-travel-agent-lab）。<br>VS Codeの設定名・ワークスペース定義で、Dev Containerと区別するために使う |
| Dev Container | VS CodeのDev Containers機能で接続する、コンテナ内の開発環境 |
