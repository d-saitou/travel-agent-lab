# 用語集

| 用語 | 定義 |
|---|---|
| 旅行履歴 | ユーザーが登録した過去の旅行の記録 |
| 会話 | 旅行プランの相談における、ユーザーとエージェントの一連のやり取り |
| 会話履歴 | 会話メタ情報と会話内容・処理状態の総称 |
| サインインID | ユーザーがサインイン時に入力する識別子 |
| 内部シークレット | frontendからbackendへのリクエストであることを証明する共有の秘密値 |
| セッショントークン | サインイン後に発行し、セッションCookieで受け渡す乱数 |
| 埋め込みベクトル | テキストの意味を数値の配列で表したもの。類似度検索に使う |
| RAG検索 | 埋め込みベクトルの類似度で旅行履歴を検索し、応答生成の文脈に含める処理 |
| チェックポインター | LangGraphの会話内容・処理状態をDBに保存する仕組み |
| Dev Host | Dev Containerの外側の開発環境（WSL 2）。<br>VS Codeの設定名・ワークスペース定義で、Dev Containerと区別するために使う |
| Dev Container | VS CodeのDev Containers機能で接続する、コンテナ内の開発環境 |
