# 生成AI活用のコツ

開発で生成AIを使う中で得た気づき・コツのメモ。

## 全般
- 「こんなことができないか」と思ったら、まず生成AIに聞く。
- 使ったことのない技術は、概要・仕組み・構築方法を生成AIに聞く。
- 使ってみたい技術や使えそうな技術を見つけたら、プロジェクトに適用できるか生成AIに聞く。

## ドキュメント作成
- 作成すべきドキュメントの種類を生成AIに提案させる。
- ドキュメントごとに記載すべき内容を生成AIに提案させる。
- 考えたことは粗くてもまずドキュメントに書き出し、生成AIに整えさせる。
- Mermaid図は生成AIにレイアウトを見やすく整えさせる。
- 複雑なMermaid図は、参考画像を生成AIに読み込ませてMermaid記法に変換させる手もある。
- 技術面・文章表現・章立てや記述の順番の観点で生成AIにレビューさせる。
- ドキュメント内・ドキュメント間の重複や不整合を生成AIにチェックさせる。
- 最後は開発者自身もレビューし、冗長な箇所は生成AIに簡潔な表現へ直させる。

## 環境構築
- プロジェクトのディレクトリ・ファイル構成を生成AIに提案させる。
- 手作業の手順は、まず自動化できないか生成AIに聞く。
